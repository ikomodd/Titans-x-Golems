# Titans x Golems (TxG)
 - **Versão:** 0.0.0
 - **Status:** em desenvolvimento, não jogável
 - **Gênero:** Estratégia baseada em turnos

# Como jogar
 - Clique no golem para seleciona-lo e faça seus movimentos
 - Tiles em azul referenciam os movimentos disponíveis e os vermelhos os ataques
 - Cada Titã/Golem na arena possuem uma série de X ações, quando você não poder mais executar mais nenhum comportamento aperte ENTER para passar para o turno do oponente
